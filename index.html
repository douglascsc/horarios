Importar planilha: etapas

Área do administrador

Atualizar os horários

Envie a planilha do Excel. O site lê os dados, monta a consulta e mostra o que precisa ser revisado. A planilha é lida aqui no seu navegador; nada é publicado antes de você confirmar com a senha.

Só os valores das células são lidos: fórmulas e macros nunca são executadas.

Passo 4 de 4 · Conferir e publicar

Conferir e publicar

O PDF de conferência traz um resumo da revisão e o quadro de todas as turmas, marcado como não publicado, para enviar à coordenação antes de publicar. Na janela de impressão, escolha "Salvar como PDF". A versão offline desta planilha gera um arquivo que abre com dois cliques, sem internet, sem publicar nada online.

A publicação ainda não foi configurada neste site. Abra Configuração da publicação abaixo (é feito uma vez só).

Configuração da publicação

Configurar (ou trocar o token)

Feito uma vez, por quem administra o site. A publicação precisa de um token de acesso que só pode gravar no repositório deste site (permissão Contents: Read and write). O token fica guardado cifrado com a senha: depois, para publicar, basta a senha. O passo a passo para gerar o token está no README do projeto.
